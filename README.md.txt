*Pneumonia Detection using CNN

** Problem
This project classifies chest X-ray images into Pneumonia and Normal.

** Dataset
The dataset has_MACOX, train, test, and val folders with two classes.

**Approach
1)Import Libraries
2)Define Dataset Paths
3)Data Preprocessing
4)Build CNN Model
5)Compile Model
6)Train Model
7)Evaluate Model
8)Plot Result

** Methodology
Used a Convolutional Neural Network (CNN) for image classification.Applied image preprocessing and normalization. Model trained using training data and validated on validation set.

** Findings
The model achieved an accuracy of around,Test Accuracy: 83.33%.

** Conclusion
The model performs well but it need to perform more better.
